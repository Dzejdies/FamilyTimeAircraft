# Family Time Aircraft 0.1.3

Aircraft can be built from the native construction menu. This release adds airfields, the fictional Aster Twin Spires, player and child pilots, passenger seating, parachute drops, destination orders, targeted crashes, impact damage and repairable wrecks. See [GAMEPLAY.md](GAMEPLAY.md) for controls and behavior.

Choose a package for the exact game build and renderer. Multiplayer requires the matching Family Time Multiplayer 0.1.14 (protocol 20) package on every participant.

Windows runtime checks were performed under Proton; native Windows execution is not verified. Build completion alone does not establish runtime parity between platforms.
